# Solo DnD

- Start with [the project guide](docs/project.md) for current behavior, working branches, and product decisions still open.
- For game design and rules work, start with [the D&D reference catalog](docs/dnd/README.md). Cite edition, source and page. Distinguish an existing game rule, a tabletop reference rule, and a design proposal.
- Treat PDFs and extracted Markdown as source material. For maps, tables, stat blocks, or uncertain extraction, check the original page. Use the local library for research when available. Use the licensed SRD and original project material as the basis for public content.
- For DM provider changes use [the comparison runbook](docs/dm-providers.md). Keep credentials on the server.
