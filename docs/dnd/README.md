# Правила и материалы для дизайна

Начните с [SRD 5.1](srd-5.1/README.md) для базовых правил пятой редакции (2014). [SRD 5.2.1](https://www.dndbeyond.com/srd) относится к обновлённой редакции. Игра использует собственные упрощения и способности. Для вопроса о текущем поведении проверяйте `src/game/`, `src/hooks/useCombat.ts` и `src/hooks/useNarrative.ts`.

## Локальная библиотека

Откройте `library.local/README.md` в checkout. Список исходных файлов хранится в [sources.json](sources.json). Каждый документ имеет стабильный идентификатор, локальный PDF и текст блоками до 12 страниц. Ссылки на правила указывают физический номер страницы PDF, который может отличаться от печатного. Для дизайна достаточно открыть нужный блок и сравнить спорное место с оригиналом.

| Что ищем | С чего начать | Как применять в Solo DnD |
| --- | --- | --- |
| Соло-игра и принятие решений без ведущего | `solo-adventurers-toolbox` | Оракул, неожиданные события, путешествия и ориентиры для соло-режима. Изучать как сторонний источник дизайна. |
| Проверки, персонаж, бой, отдых | `basic-player-5e-en`, `players-handbook-5e-ru`, открытый SRD 5.1 | Сверять проверку характеристики, бонус мастерства, преимущество, инициативу, AC и расход ресурсов. Записывать упрощения явно. |
| Встречи и противники | `basic-dm-5e-en`, `dungeon-masters-guide-5e-ru`, `monster-manual-5e-ru` | Сверять трактовку статблоков и причины, по которым бой ощутим для одного героя. Для публичных статблоков проверять наличие именно в SRD. |
| Структура приключения | `essentials-kit-ru`, `lost-mine-ru`, `sheep-adventure-ru` | Изучать крючки, темп, свободу действий и последствия. Писать свои сцены, карту и персонажей. |
| Оригинал Lost Mine | `lost-mine-en` | Английский скан. Для текстового поиска использовать `lost-mine-ru`, для проверки оригинала открыть страницу PDF. |
| Интерфейс листа персонажа | `character-sheet-2024-en` | Ориентир по группировке информации. Правила 2024 сверять отдельно. |
| Сравнение предыдущих редакций | `players-handbook-35-ru` | Историческая справка. Правило 3.5 требует отдельного решения перед переносом в механику на базе 5e. |

Картинки персонажей, таверны и кампании, а также браузерное расширение Roll20 из исходной папки не входят в справочник правил. Для включения изображений в проект потребуется разобраться с их происхождением и правами.

Для повторного импорта укажите путь к папке с PDF:

```powershell
python -m pip install pypdf
python scripts/import-dnd-library.py 'C:\путь\к\DnD'
```

Для PDF со сложными таблицами, картами, иллюстрациями или сканами используйте оригинал. Индекс каждого документа перечисляет страницы, где инструмент извлёк мало текста. Распознанные абзацы могли поменяться местами на многоколоночной странице.

## Как использовать источники в работе

- Пишите, какое правило проверили, в какой редакции и на какой странице. Если в игре правило отличается, отметьте текущую реализацию и предложенное изменение отдельно.
- При подготовке публичного контента опирайтесь на материал, лицензированный в SRD, и собственные тексты проекта. Перевод, PDF и полная транскрипция из частной библиотеки остаются локальными при отсутствии подтверждённого права на публикацию.
- Материалы справочника нужны для проектирования и проверки механик. Достаточно передать агенту подходящие страницы и контекст задачи. Игровому мастеру в рантайме нужны правила самой игры, состояние и текущее приключение.
